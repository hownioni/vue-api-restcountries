Consumo de API usando fetch() Interfaz de Usuario

Demostración de datos obtenidos en vivo desde la API REST Countries v5.

Explicación del cumplimiento

La aplicación web consume de forma asíncrona la información de países mediante la función nativa fetch() conectándose directamente al endpoint oficial de la API REST Countries v5 (https://api.restcountries.com/countries/v5?q=Canada&api-key=rc_live_demo&pretty=1).

Como se observa en la parte superior, el sistema incluye un indicador visual "● API v5 Conectada" que valida la comunicación exitosa con el servicio remoto y muestra de inmediato los datos de Canadá (bandera oficial en SVG/PNG, capital Ottawa, región Americas y población de 41,798,407 habitantes).

Consumo de API usando fetch() Código Fuente

Implementación de la llamada HTTP asíncrona con fetch() y procesamiento JSON.

Explicación del cumplimiento

En el archivo src/App.vue, se realiza la petición asíncrona con await fetch(urlConsulta) hacia la dirección indicada en las instrucciones. La respuesta HTTP es evaluada mediante respuesta.ok para capturar oportunamente cualquier código de error del servidor.

Posteriormente, el cuerpo de la respuesta se convierte a objeto JavaScript con await respuesta.json(), se extrae el arreglo data.objects y los campos son normalizados antes de asignarse a la variable reactiva paises.value para su posterior renderizado reactivo.

Explicación del cumplimiento

Estructuras de control v-if, v-else-if y v-else Código Fuente

Bloque condicional estructurado para la gestión reactiva de estados en el template.

Explicación del cumplimiento

En el cuerpo principal de App.vue, se diseñó una cadena de control condicional completa: v-if="cargando" para el spinner de espera, v-else-if="error && paises.length === 0" para fallas críticas, v-else-if="paisesFiltrados.length === 0" para filtros vacíos, y finalmente la cláusula v-else para mostrar la lista completa.

Especificación 8 • Manejo de Errores vue-api-restcountries

Manejo de errores con try / catch Código Fuente

Estructura try / catch / finally para captura robusta de excepciones.

Explicación del cumplimiento

En src/App.vue, la rutina asíncrona de consulta está encapsulada dentro de un bloque try { ... } catch (err) { ... } finally { ... }. Dentro del try, se valida respuesta.ok y se lanzan excepciones explícitas ante códigos HTTP 4xx o 5xx.

El bloque catch registra el error en consola, asigna el mensaje a la variable reactiva error.value y activa el catálogo de contingencia, mientras que el bloque finally garantiza que cargando.value = false se ejecute siempre.
